# 成长型完整自传设计

## 目标

照片故事是不可变的素材原稿；完整自传是基于全部原稿重新取材、编排和转述的独立作品。第一张照片即可生成“微型自传”，后续照片加入后生成新的不可变版本，并允许回看上一版。

## 内容分层

1. `PhotoStory`：照片、访谈和详细文章，不被成书流程覆盖。
2. `Timeline Memory`：当前有效的人物、时间、地点、关系和事件事实。
3. `AutobiographyEdition`：第三人称完整作品，包含序、整书章节、后记、人物画像、来源快照和终审结果。

## 成书规则

- 只有一篇照片故事时生成有开端、主体、回望和尾声的微型自传。
- 新照片加入后，比较上一版来源快照，记录新增和更新的照片故事。
- 六篇以上素材重组为四至六个真正的人生章节，至少两章融合多篇照片故事，避免“一张照片一章”。
- 照片必须进入正文场景，并说明它为何被主人公留下。
- 主人公的特点通过选择、行动、代价和变化表现，不用抽象赞美替代故事。
- 全文使用第三人称；仅有来源的直接引语可以出现第一人称。
- 当前确认事实优先于旧照片文章中的跨章引用，避免过期年龄、工龄和人物关系污染新书。

## 增量版本

每个版本保存 `previous_edition_id`、章节版本映射、照片 ID、事实 ID、`added_chapter_ids` 和 `updated_chapter_ids`。生成新自传不会改写照片故事；确认和回退也只移动完整自传的阅读版本。

## 验收

- 第三人称一致性为 100%。
- 照片与来源故事覆盖率为 100%。
- 六篇以上素材形成四至六个整书章节，且至少两章融合多篇素材。
- 文学性与人物价值终审不低于 4/5。
- 时间、年龄、人物关系、工龄与当前事实一致。
- 成书前后照片故事的当前版本 ID 保持不变。
