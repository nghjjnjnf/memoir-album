# 模型分层与章节生成讨论稿

状态：待通过样本评测后决策  
整理日期：2026-08-23

## 1. 关键结论

首版不建议让一个实时语音大模型直接包办整个流程。建议采用可替换的分层管线：

```text
录音 → ASR 转写 → 访谈/记忆模型 → 章节生成模型 → 事实审校 → TTS 朗读
                    ↑
              照片视觉理解
```

优势是原始材料可追溯、错误容易定位、每层可以独立更换供应商，也更容易控制“不得编造”的底线。

## 2. 模型任务分层

### 2.1 ASR：语音转文字

必须重点评估：

- 老年人语速慢、停顿多、声音较轻时的准确率；
- 普通话口音和地方方言；
- 人名、地名、旧单位名称和年代词；
- 环境噪声及家属插话；
- 标点、分句和时间戳；
- 是否支持自定义热词；
- 成本、延迟、数据保存和合规要求。

首版建议采用“按住或点击录制一段，结束后转写”，同时保存原始音频。实时字幕可以显示，但不应成为创作能否继续的前提。

当前候选池：

- 国内主候选：科大讯飞、火山引擎、腾讯云等，重点测试方言和老人真实录音；
- 国际对照：OpenAI GPT-Transcribe；
- 第二阶段实时字幕候选：国内流式 ASR 或 OpenAI GPT-Live-Transcribe。

官方资料显示，GPT-Transcribe 面向完成文件、流式文件及 Realtime 已提交语音段，支持关键词和语言提示；GPT-Live-Transcribe 面向低延迟实时转写。讯飞流式听写官方文档列出多方言免切、热词与动态修正能力。

### 2.2 图片理解

任务不是识别人名，而是生成安全的访谈线索：

- 可见人物、场景、物件、服饰和活动；
- 画面中可能值得询问的细节；
- 照片质量、方向和是否需要重新拍摄；
- 不得把视觉推测直接写入章节。

图片理解可以与访谈主模型共用一个支持图像输入的多模态模型。正式选型要用真实旧照片评估模糊、反光、翻拍和黑白照片表现。

### 2.3 访谈与记忆模型

主要职责：

- 判断下一步最值得问的一个问题；
- 维持“知心小妹妹”的行为边界；
- 将口述内容整理为结构化事实、原话和未确认信息；
- 决定继续追问、先生成草稿或建议暂停；
- 调用保存故事、更新人物、生成章节等后端工具。

这层优先看指令遵循、结构化输出、中文自然度、图像理解、工具调用稳定性、延迟与成本。

OpenAI 路线的初步候选为 GPT-5.6 Terra 作为质量与成本平衡的主模型，GPT-5.6 Luna 可用于高频、低风险的分类和信息抽取；最终章节或复杂一致性检查可用 GPT-5.6 Sol 作为质量上限对照。是否采用必须通过中文口述样本评测，而不能仅凭模型排名决定。

### 2.4 章节生成与审校模型

章节生成需要良好的中文叙事、长上下文、风格控制和事实约束。可以与访谈模型同源，也可以采用更高质量模型生成最终版本。

不建议一次调用直接从完整聊天生成正文。应使用第 4 节的多阶段流程，并由独立审校步骤检查新增事实。

### 2.5 TTS：文字转语音

需要评估：

- 普通话清晰度和自然停顿；
- 年轻女性声音是否温柔但不过度表演；
- 长章节朗读稳定性；
- 语速、音量和停顿是否可调；
- 方言朗读需求；
- 用户是否明确知道这是 AI 合成语音。

OpenAI 当前提供 GPT-4o mini TTS；国内也应选择两到三家中文 TTS 进行盲听。首版无需声音克隆，避免额外的授权与滥用风险。

## 3. 推荐的首版语音方案

1. 小程序录制 30 秒至 3 分钟的自然语音片段；
2. 音频上传对象存储并立即创建不可变的原始记录；
3. ASR 返回带时间信息的转写；
4. 老人或协作者可纠正重要人名和地名；
5. 访谈模型根据转写更新人生记忆并产生一个问题；
6. 问题同时显示文字并使用 TTS 播放；
7. 章节生成后分段朗读并接受语音修改。

如果存在家属插话，首版可先提示轮流讲话；自动说话人分离可作为后续能力。

## 4. 章节生成管线

### 阶段 A：材料归档

保存照片、原始语音、ASR 转写、人工纠正和对话轮次。原始材料不得被成稿覆盖。

### 阶段 B：记忆卡片

生成结构化对象：

- 核心事件；
- 人物和关系；
- 时间及置信状态；
- 地点；
- 事情经过；
- 关键选择或转折；
- 具体细节；
- 当时感受；
- 现在回望；
- 可保留的原话；
- 未确认信息；
- 敏感及分享限制；
- 信息来源。

### 阶段 C：成稿准备度判断

至少应具备：一个明确的中心事件、叙述者在事件中的位置、基本经过，以及一个具体细节或个人感受。信息不足时最多继续询问一至三个高价值问题；老人不愿继续时仍可生成短故事，并诚实保留模糊处。

### 阶段 D：叙事规划

模型先选择合适的章节类型和结构，例如人物回忆、人生转折、日常生活、工作经历、迁徙或家庭故事。它同时根据人称、章节类型和情感基调检索适用的写作方法卡。输出简短提纲，不直接开始文学扩写。

### 阶段 E：第一人称草稿

按照个人写作档案生成：

- 按本书或本章选定的第一人称/第三人称叙述；
- 默认七分原声、三分编辑；
- 可以调整顺序、去除口语重复并增加衔接；
- 不得添加没有来源的场景、对话、动作、心理和因果；
- 时间不确定时使用真实的模糊表达。

### 阶段 F：事实与风格双审校

事实审校检查每个具体陈述是否有来源；风格审校检查是否像同一个人在说话、是否过度煽情、是否存在模板化结尾。审校发现问题后只修复问题句，不重新任意扩写全文。

### 阶段 G：老人确认

分段朗读草稿，接收语音修改。老人可将内容标记为：保存但不入书、进入书稿但不分享、允许指定亲友阅读或允许分享。

## 5. 照片与章节的层级

已确定采用“第一张照片即可成章”的规则：

```text
上传照片 → 完成访谈 → 立即生成一章
                         ↓
上传新照片 → 判断关联 ──┼─ 加入已有章节
                         ├─ 合并两个章节
                         └─ 另起一章
```

第一张照片完成对话后必须能够获得一个独立、可确认、可分享的章节。后续照片到来时，Agent 根据事件是否相同、时间是否连续、核心人物是否重合、主题是否一致和叙事是否完整给出建议。合并不是自动操作，老人或授权协作者拥有最终决定权。

如果章节已经分享，合并操作创建新版本；原分享内容在重新确认前不被直接覆盖。

## 6. 选型方法

不应只比较厂商宣传参数。建立匿名化真实测试集，至少覆盖：

- 普通话、明显口音和目标用户常见方言；
- 安静房间、电视背景声和家属插话；
- 人名、地名、旧称和年代；
- 黑白照片、模糊翻拍和多人合影；
- 温暖故事、普通日常和敏感经历。

评测指标：

- ASR：字错误率、专名准确率、分句质量、延迟和成本；
- 访谈：问题价值、自然度、重复率、是否诱导、是否一次只问一个问题；
- 写作：事实忠实度、老人声音相似度、可读性、文学性、敏感信息处理；
- TTS：清晰度、自然度、亲切但不过度表演、老年人听懂率。

最终选择应以目标老人盲测和人工评分为准，并在系统中保留模型供应商适配层，避免后期被单一模型锁定。

## 7. 尚待讨论的决策

1. 首发用户主要使用普通话，还是必须从第一版支持若干方言；
2. 每次录音期望时长以及是否需要实时字幕；
3. 章节目标长度与成稿等待时间；
4. 一张照片生成的初始章节目标篇幅和最少信息标准；
5. 默认文风和可选文风的数量；
6. 是否允许家属共同录音及多说话人识别；
7. 预算、并发量、国内部署和数据驻留要求。
