# 文学化自传章节生成规范与正面示例

状态：规范完成；原创 few-shot、视觉证据写作、文学推断记录和快捷修订已接入  
整理日期：2026-08-24  
适用范围：照片访谈、章节规划、章节生成、事实审校、风格审校和用户修订

## 1. 问题记录

当前章节能够覆盖老人讲述的时间、地点、人物和事件，但生成结果仍接近“事实整理稿”或“工作纪实”，没有达到面向老人展示的文学初稿质量。

以测试章节《车间门口的那张合影》为例，主要问题包括：

1. 开头直接报告时间地点，像照片说明，没有利用照片中的人物、服饰、建筑和物件建立画面；
2. 人物只有姓名、关系和工作分工，缺少能体现性格与关系的动作、语言和细节；
3. “发现半毫米偏差”“早班现场验证”“获奖拍照”等转折点均被压缩成摘要，没有写成读者可以进入的场景；
4. 情绪以“害怕、过意不去、开心”等概括词直接说明，没有通过选择、动作、停顿和具体念头呈现；
5. 1980年代县城工厂的生活质感没有充分体现，广播、蓝工装、烟盒纸、夜校和食堂红烧肉等细节没有形成时代氛围；
6. 全章按照访谈事实出现顺序依次复述，没有先提炼主题、意象和情感弧线；
7. “从不敢开口、想站到后面，到被叫到前面”本可以成为核心主题，但没有被组织成章节主线；
8. 老人的原话被大量改写成统一书面语，个人语言指纹不足；
9. 结尾结束了事件，却没有完成“现在的我如何看待当年的我”的自传回望；
10. 为了避免编造，事实审校可能把文学表达一并压平，导致成稿安全但平淡；
11. 章节约 645 字，对已有 7 轮访谈和 35 条事实利用不足；
12. 前台直接呈现低完成度事实稿，不符合“先给老人一份好看的版本，再让老人按意愿修改”的产品目标。

## 2. 产品目标

老人第一次点击“生成章节”时，默认看到的是一份完成度较高的“温暖文学版”，而不是后台事实摘要。

理想体验是：

> 原来我的经历也可以被写得这么好看，而且这确实还是我的故事。

章节生成后，系统说明文字做了适当润色，但没有改变用户讲述的经历，并提供低门槛修改入口：

- 就用这一版；
- 写得更朴实；
- 再有画面一些；
- 情感再深一点；
- 减少文学修饰；
- 有一处不准确；
- 我还想补充；
- 换一个标题。

任何修改都创建新版本，不覆盖老人已经确认或分享的版本。

默认首稿采用“先写得好看，再让用户修正”的产品策略：人物、时间、地点、关系、核心事件、结果和直接引语不得改动；与证据不冲突的氛围、动作、心理弧线、象征和如今回望可以由作家主动完成，不要求老人逐句预先确认。系统在后台保存这些文学推断，前台提供清晰的事实纠错和文风修订入口。

## 3. 调研结论

### 3.1 口述史访谈必须为文学写作收集材料

Smithsonian 的口述史指南强调：访谈者应使用开放式问题，一次只问一个简单问题，紧跟意外出现的细节，并让叙述者讲述自己的参与、感受和处理过程；照片和人生时间线可以帮助唤起记忆，访谈结束时应邀请叙述者评价经历与人生。[Smithsonian Institution Archives：How to Do Oral History](https://siarchives.si.edu/history/how-do-oral-history)

Oral History Association 进一步强调主动倾听、澄清、展开与反思，并要求保留叙述者自己的视角和语言，避免操纵或歪曲原话；在公开前应尽可能给叙述者审核确认的机会。[Oral History Association：Oral History Best Practices](https://oralhistory.org/best-practices/)

因此，访谈准备度不能只检查“时间、地点、人物、经过”，还应检查：

- 是否有一个值得放慢描写的转折场景；
- 是否有一个可辨认的人物动作或语言；
- 是否有至少一个经过确认的视觉或感官细节；
- 是否有当时的感受；
- 是否有现在回望这件事的意义；
- 是否保留了老人自己的代表性表达。

### 3.2 转折点应写成场景，摘要只负责过渡

作家 Lee Martin 指出，改变人物关系、处境或认识的重要时刻通常值得写成场景；场景需要明确的关键时刻，并通过感官细节、有效对话、节奏与逐步升高的张力，让读者经历变化，而不是只知道结果。[Lee Martin：Making Scenes in a Memoir](https://leemartinauthor.com/2016/07/04/making-scenes-memoir/)

据此，本项目采用以下区分：

- 场景：重要发现、选择、冲突、关系变化、第一次、告别、重逢、被认可等；
- 摘要：跨越时间、交代背景、连接两个场景、说明重复发生的日常；
- 回望：现在的叙述者解释这件事为什么仍值得记住。

一章不能全是场景，否则节奏疲惫；也不能全是摘要，否则只剩信息。默认结构建议为“照片或物件开场 → 场景 → 简短背景 → 核心场景 → 结果 → 现在回望”。

### 3.3 感官细节必须准确且有选择

San Francisco Writers Conference 的回忆录写作建议强调，视觉之外的声音、气味、触感和味觉可以让页面鲜活，感官选择也能间接传递人物情绪。[SFWC：Memoir Tips—Engage Your Reader’s Senses](https://www.sfwriters.org/memoir-tips-engage-your-readers-senses/)

本项目不能据常识自动补写“机器轰鸣、机油味、秋风、阳光”等内容。处理规则是：

- 照片直接可见的内容，可以作为视觉描写；
- 老人明确讲述的声音、气味、触感和味觉，可以写入场景；
- 高价值但缺失的感官信息，由访谈 Agent 温和追问；
- 老人记不清时保留模糊，不要求其迎合模型；
- 不为凑齐五感而堆砌细节，一两个准确细节优于一整段通用形容词。

### 3.4 记忆可以被组织，但不能被悄悄替换

Creative Nonfiction 关于场景与对话重构的讨论指出，回忆录写作者需要尽力按照记忆还原场景，同时诚实面对记忆中的缺口，并在可能时用照片、文档或其他见证者核查。[Creative Nonfiction：Reconstruction of Scene and Dialogue](https://creativenonfiction.org/writing/reconstruction-of-scene-and-dialogue/)

本项目比普通个人写作工具采用更严格边界：

- 允许重新排序、设置悬念、调整段落节奏和使用修辞；
- 允许把已经确认的动作、原话和视觉证据组织成场景；
- 不自动创作几十年前的直接对话；
- 不把模型推测写成老人内心；
- 对模糊日期使用“那年秋天前后”“大约是”等诚实表述；
- 如果老人只记得对话大意，优先使用间接引语；
- 任何会改变人物形象、事件因果或人生意义的补写都必须再次确认。

### 3.5 章节结构应服务主题，而不是服务事实列表

Writer’s Digest 的回忆录结构建议认为，结构不只是时间顺序，而是意义的组织；应先识别核心主题、范围和情感弧线，再决定使用线性、循环、主题式或其他结构。[Writer’s Digest：5 Tips for Figuring Out the Structure of Your Memoir](https://www.writersdigest.com/5-tips-for-figuring-out-the-structure-of-your-memoir)

一张照片生成一章时，默认不等于机械地从最早事实写到最晚事实。章节导演应先回答：

1. 这张照片表面记录了什么？
2. 这段经历真正改变了什么？
3. 哪个物件、动作或原话最能代表这次变化？
4. 哪一幕应该放慢，哪部分只需交代？
5. 结尾回到照片时，老人如今看见的是否已经不同？

## 4. 文学美化的允许边界

核心原则：事实不能美化，表达可以美化；经历不能虚构，叙事可以有文学性。

### 4.1 允许

- 调整事实呈现顺序；
- 从照片、物件或关键动作切入；
- 使用比喻、对照、反复、留白和首尾呼应；
- 把多个已经确认的连续动作写成完整场景；
- 删除无关信息，压缩次要时间段；
- 保留并突出老人有辨识度的原话；
- 在不改变含义的前提下整理口语重复；
- 使用“当时的我”和“现在的我”形成双重视角；
- 根据老人选择，在朴实、温暖、幽默、克制等文风间调整。

### 4.2 必须确认后才能使用

- 天气、温度、声音、气味、触感和味道；
- 人物具体表情、神态、动作和穿着细节；
- 多年前的直接对话；
- 他人的心理和动机；
- 事件对老人后来人生的具体影响；
- 具有评价性的时代背景；
- “第一次”“一生中最……”等绝对化判断。

### 4.3 禁止

- 新增人物、时间、地点、关系和结果；
- 为增强戏剧性制造冲突、贫困、疾病、牺牲或遗憾；
- 把视觉模型猜测升级为人生事实；
- 把写作范例中的人物、物件、时代或情节迁移进当前故事；
- 模仿在世作家的独特文风；
- 用空泛的苦难、奋斗、时代洪流和岁月沉淀套话替代具体经历；
- 为了文学性篡改老人朴素但有辨识度的表达。

## 5. 推荐的多阶段生成流程

```text
个人事实与原话
        +
已确认视觉/感官证据
        ↓
材料缺口检查 ──缺少高价值内容──→ 访谈 Agent 再问 1 个问题
        ↓
章节导演：主题、意象、场景、节奏、结尾
        ↓
文学写作 Agent：生成“温暖文学版”
        ↓
事实审校：检查新增事实和错误因果
        ↓
风格审校：检查流水账、套话、过度煽情和声音失真
        ↓
前台展示文学初稿
        ↓
老人确认或选择低门槛修改
```

事实审校只能删除或改写没有来源的事实性断言，不能因为句子包含比喻、节奏变化或象征就自动压平。

## 7. 写作 Agent Prompt 模板

```text
你是中文自传的文学写作编辑。你的任务不是整理会议纪要，而是把老人已经确认的经历写成真实、温暖、有画面、有个人声音的自传章节。

[最高原则]
1. 事实不能美化，表达可以美化；经历不能虚构，叙事可以有文学性。
2. 只能把“已确认事实”和“已确认视觉/感官证据”写成事实。
3. 写作方法和示例只影响结构、节奏与修辞，不得带入其中的人物、地点、时代、物件或情节。
4. 不模仿特定作家，不复制示例措辞。

[写作目标]
- 默认生成完成度较高的“温暖文学版”，不要先输出事实摘要。
- 以第一人称或指定人称写作，像这个老人本人经过一位好编辑帮助后讲出来。
- 根据材料量生成约 1000—1800 个汉字；材料不足时宁可写短，也不要填充虚构内容。
- 开头从照片、物件、动作或转折瞬间切入，不以时间地点清单开头。
- 至少选择 2 个关键时刻写成场景，其余信息用摘要连接。
- 每个场景使用 1—3 个有来源的具体细节，不堆砌五感。
- 保留老人有辨识度的原话、称呼和句式。
- 建立清晰的情感弧线和一个贯穿全文的核心意象。
- 结尾优先回到开头的照片、物件或动作，再写现在的回望；没有回望材料时克制收束，不代替老人总结人生。

[语言要求]
- 朴素而有文学性，避免华丽辞藻连续堆叠。
- 长短句交替，段落有呼吸感。
- 少用“岁月、时光、命运、时代洪流、弥足珍贵、熠熠生辉”等模板词。
- 少直接说“我很感动、我很坚强”，优先用动作、选择和具体细节表现。
- 不向读者解释后台事实、识图、RAG、模型或审校过程。

[输出]
只输出：章节标题 + 章节正文。
```

## 8. 给 LLM 的原创正面示例

以下示例均为本项目原创，可进入写作方法库。它们只示范写作功能，不允许模型复制句子或迁移事实。

### 示例 1：从照片进入回忆

适用技巧：照片开场、视觉证据、物件意象。

输入事实：1985年10月；井研县机械厂；六名工人穿蓝色工作服；红砖厂房和绿色木门；两人举着奖状；叙述者是左边第五位短发女工；刚下机床，衣服上有油。

正面输出：

> 四十多年后再看这张合影，我第一眼认出的，还是那一排蓝色工作服。身后是机械厂的红砖车间，两扇绿色木门向外敞着，墙边露着沉重的机械部件。照片正中，两位工友共同托着一张奖状；我站在左边第五个，留着短发，刚从机床边下来，工作服上还带着油。谁能想到，这张薄薄的奖状，最早只是从几张烟盒纸和半毫米的偏差开始的。

学习点：不以档案字段开头；所有画面均来自照片或用户确认；最后一句用“奖状—烟盒纸—半毫米”建立悬念。

### 示例 2：把转折点写成场景

适用技巧：动作、冲突、节奏、少量直接引语。

输入事实：早班点名；叙述者把三天记录的烟盒纸摊在工作台；王师傅认为机器用了十几年不会有事；张组长让她拿废料现场验证；测量确认是夹具问题。

正面输出：

> 早班点名的时候，我把那几张烟盒纸带在身上，却一直没敢拿出来。车间里的女车工本来就少，我怕自己一开口，别人会说我多管闲事。等人快散了，我才把纸摊到工作台上，请张组长看那一串编号。王师傅听完，摇摇头：“这机器用了十几年，能有什么事？”张组长没有急着下结论，只让我拿一件废料当场试。卡尺落下去，那个总往同一边偏的半毫米又出现了。那一刻我才慢慢松开一直攥着的手。

学习点：把已经确认的连续事实放慢；用动作承载紧张。末句“攥着的手”只有在老人确认该动作后才能采用；如果未确认，应删去或先追问。

### 示例 3：用一件小事写人物关系

适用技巧：人物塑造、原话、家庭与工作交织。

输入事实：陈国强是丈夫；二人在厂夜校相识，1981年结婚；他看到叙述者吃饭时仍在比画草图，主动留下帮忙，并说“你既然看准了，我陪你试到底”；女儿两岁，婆婆帮忙照看两个晚上。

正面输出：

> 国强知道我不是爱逞强的人。那几天我把草图带回家，吃着饭还忍不住在桌边比画，他看了一阵，没有劝我算了，只说：“你既然看准了，我陪你试到底。”我们1973年在厂里认识，1975年结了婚，1981年又一起上过夜校。十年以后，他还是坐在我身边听我讲那些尺寸和零件。那两个晚上，婆婆替我们照看两岁的女儿，他跟我一起回到车间，一遍遍磨那块新的定位件。

学习点：不评价丈夫“伟大、体贴”，而是用他说的话和留下帮忙的行动表现关系。

### 示例 4：从具体物件提炼主题

适用技巧：象征、克制回望、首尾呼应。

输入事实：叙述者连续三天在烟盒纸上记废品编号；发现同方向偏半毫米；因此提出修改夹具；后来获得集体奖状。

正面输出：

> 后来，人们记住的是那张盖着红章的奖状。我记得更清楚的，却是几张被我写满编号的烟盒纸。奖状挂起来很好看，烟盒纸却早不知道丢到哪里去了。可如果没有纸上那个不起眼的半毫米，也就不会有照片里的那一天。年轻时的我并不觉得自己做了多大的事，只是觉得看见了问题，就该把它弄明白。

学习点：以奖状和烟盒纸形成对照；回望保持朴素，不上升为空泛的奋斗口号。“烟盒纸已遗失”和最后一句态度必须得到老人确认后才能作为最终正文。

### 示例 5：以位置变化完成章节结尾

适用技巧：动作呼应、人物成长、照片回扣。

输入事实：拍照时叙述者本想躲在后面；张组长把她叫到前面；照完相食堂加了一盘红烧肉；她一路笑着回家。

正面输出：

> 宣传科的小赵举起相机时，我下意识想往后站。张组长看见了，招手把我叫到前面。我们六个人就这样站在红砖车间门口，工作服上的油还没来得及擦，两个人在中间托着奖状。照完相，食堂给我们加了一盘红烧肉，我一路笑着回家。照片把那一刻留了下来，也把那个总怕自己多管闲事的我，留在了队伍前面。

学习点：没有额外说“我从此变得自信”，而是用“从后面到前面”的真实动作完成含蓄的成长表达。

### 示例 6：诚实处理记忆模糊

适用技巧：不确定记忆、避免假精确、保留口述感。

输入事实：老人只记得照片大约拍于1970年代初；可能是春天；地点确定为老家院子；不记得拍照人；记得母亲让大家换上干净衣服。

正面输出：

> 这张照片究竟是哪一年拍的，我已经说不准了，大约是七十年代初。看院子里的样子，像是春天，也可能只是我后来给这段记忆添上的季节。拍照的人是谁，我也想不起来。唯独记得母亲那天催着我们换上干净衣服，还站在门口把我的衣领重新理了一遍。年月模糊了，她手上的那个动作却一直很清楚。

学习点：不把猜测写成确定事实；记不清本身也可以形成真实而动人的叙述。

## 9. 风格审校清单

风格审校 Agent 应逐项检查：

- [ ] 开头是否像档案说明或会议纪要；
- [ ] 是否存在一个清晰主题，而不是事实平均铺陈；
- [ ] 是否至少有两个值得放慢的场景；
- [ ] 转折点是否被一句“后来成功了”快速跳过；
- [ ] 环境和人物细节是否都有证据；
- [ ] 情绪是否只靠“开心、难过、感动、坚强”直接说明；
- [ ] 人物是否只有姓名与关系，没有动作、语言或辨识度；
- [ ] 是否保留了老人的原话和口头节奏；
- [ ] 是否存在过度华丽、连续比喻或空泛升华；
- [ ] 是否存在模板化的“岁月、时光、珍贵、人生旅程”结尾；
- [ ] 结尾是否回应开头或核心意象；
- [ ] 现在回望是否与已知经历一致，并在后台标记为文学推断；
- [ ] 章节长度是否与材料丰富度相称；
- [ ] 文学修订是否改变了人物形象、事件因果或事实含义。

## 10. 验收标准

使用同一批访谈材料，对比旧版事实稿和新版文学稿。老人、家属与编辑进行盲评：

| 指标 | 最低目标 |
|---|---:|
| 事实忠实度 | 不低于旧版 |
| 老人声音相似度 | 不低于旧版 |
| 文学性 | 平均提升至少 1 分（5分制） |
| 画面感 | 平均提升至少 1 分（5分制） |
| 情感自然度 | 不出现明显煽情或替老人升华 |
| 新增无来源硬事实 | 0 |
| 模板化表达 | 每章不超过 1 处，最终目标为 0 |
| 用户首稿接受率 | 记录并持续提高 |

技术测试还应检查：

- 每个硬事实能够追溯到事实卡或原话；画面细节追溯到照片；文学加工保存为推断清单；
- 示例中的人物和情节不会泄漏到其他故事；
- “更朴实”“更有画面”“减少修饰”等操作只创建新版本；
- 老人纠正事实后，旧文学稿不会反向污染个人事实库；
- 已分享版本不会随新文学稿静默变化。
