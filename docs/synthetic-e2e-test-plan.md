# 三张合成照片端到端测试方案

更新日期：2026-08-23

## 1. 测试目标

验证本地测试版能否用三张虚构照片完成：

```text
上传照片
→ 三轮文字访谈
→ 事实提取
→ 章节生成
→ 写作方法检索
→ 事实/风格/隐私审校
→ 确认与分享
→ 新照片关系判断
→ 独立成章或合并成新版本
→ 导出完整项目
```

图片只作为记忆入口。本轮 DeepSeek 接口仍是文字 Chat Completions，不把图片内容发送给 DeepSeek，也不将图中文字识别冒充成视觉模型能力。

## 2. 合成测试素材

| 素材 | 虚构时间 | 主题 | 预期关系 |
|---|---:|---|---|
| `synthetic-1985-factory.png` | 1985 | 县城机械厂与师傅同事 | 首章 |
| `synthetic-1992-spring-festival.png` | 1992 | 春节家庭团聚 | 独立章节 |
| `synthetic-2003-retirement.png` | 2003 | 退休与工作回望 | 合并进工作章节的新版本 |

所有人物和讲述均为虚构，不能用于产品质量宣传或代表真实老年用户反馈。

## 3. 通过条件

- 三张图片均上传成功；
- 每组完成三轮访谈并保存事实证据；
- 每组都能生成章节并保存审校报告；
- 章节版本保存写作方法卡或合并来源快照；
- 1992 故事独立成章；
- 2003 故事合并后，1985 工作章节创建 v2；
- 合并前的 v1 和旧分享链接保持可读；
- 最终目录为两章；
- 项目可导出；
- DeepSeek 测试中所有 `model_runs.provider` 必须为 `deepseek`；
- DeepSeek 测试中 `fallback` 数量必须为 0，任何一次降级都判定整轮失败。

## 4. 测试命令

无外部调用的流程基线：

```powershell
.\.venv\Scripts\python.exe .\scripts\run_synthetic_e2e.py --provider mock
```

真实 DeepSeek 测试使用安全终端提示，不把密钥写入命令、文件或报告：

```powershell
.\run-deepseek-e2e.ps1
```

已经在聊天中出现过的密钥必须先撤销并重新生成。
